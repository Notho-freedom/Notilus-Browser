# Mosaïque

La mosaïque permet d'organiser visuellement vos contenus dans un workspace personnalisable.

## Types de contenu

- **Pages web** : Affichez plusieurs sites simultanément
- **Terminal** : Intégrez des terminaux dans la mosaïque
- **DevTools** : Panneaux de développement
- **Widgets** : Widgets système et métriques
- **Personnalisé** : Contenu personnalisé

## Fonctionnalités

- **Drag & Drop** : Réorganisez les tuiles par glisser-déposer
- **Redimensionnement** : Ajustez la taille des tuiles
- **Workspaces** : Créez plusieurs workspaces
- **Sauvegarde** : Les configurations sont sauvegardées automatiquement

## Utilisation

1. Activez la mosaïque via la sidebar ou `Ctrl+Shift+M`
2. Cliquez sur une tuile vide pour ajouter du contenu
3. Sélectionnez le type de contenu souhaité
4. Organisez votre workspace selon vos besoins

## Raccourcis

- `Ctrl+Shift+M` : Basculer la mosaïque
- `Ctrl+N` : Nouvelle tuile
- `Delete` : Supprimer la tuile sélectionnée

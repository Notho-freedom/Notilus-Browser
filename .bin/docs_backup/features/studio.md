# Notilus Studio

Notilus Studio est une suite complète d'outils de test front-end.

## Modules

### Responsive Tester Pro
- Multi-viewports simultanés (jusqu'à 6)
- Synchronisation du scroll
- Détection automatique des breakpoints CSS
- Analyse des problèmes de responsivité
- Rotation des viewports

### Mockup Comparator
- Comparaison pixel-par-pixel avec des mockups
- Différents modes de comparaison (overlay, slide, diff)
- Détection automatique des différences
- Historique des comparaisons

### Live Editor Pro
- Édition live du HTML/CSS/JavaScript
- Historique des modifications
- Export des changements
- Application immédiate sur la page

### Screenshot Studio
- Capture avec différentes options (viewport, full page, element)
- Formats multiples (PNG, JPEG, WebP)
- Intégration avec les mockups
- Historique des captures

### Interaction Recorder
- Enregistrement des interactions utilisateur
- Génération de scripts d'automatisation
- Playback des interactions
- Export en différents formats

## Utilisation

1. Ouvrez Notilus Studio via la sidebar ou `Ctrl+Shift+S`
2. Sélectionnez le module souhaité
3. Attachez Studio à un onglet web actif
4. Utilisez les outils selon vos besoins

## Raccourcis

- `Ctrl+Shift+S` : Ouvrir Notilus Studio
- `Ctrl+Shift+R` : Lancer l'analyse responsive

# Notilus Lighthouse

Notilus Lighthouse offre une analyse complète de performance, accessibilité, SEO et sécurité.

## Modules

### Performance Analyzer
- Core Web Vitals (LCP, FID, CLS, TTFB, TTI, TBT)
- Score de performance global
- Métriques détaillées
- Recommandations d'optimisation

### Issue Detector
- Détection automatique des problèmes
- Identification des causes racines
- Suggestions d'amélioration
- Priorisation des problèmes

### History & Trends
- Historique des audits
- Graphiques de tendances
- Détection de régressions
- Comparaison temporelle

### AI Advisor
- Recommandations priorisées
- Quick wins identifiés
- Chat contextuel
- Plans d'action détaillés

### Report Generator
- Export PDF, JSON, CSV
- Rapports personnalisables
- Partage des résultats
- Historique des rapports

## Audit Rules

Plus de 100 règles d'audit couvrant :
- **Accessibilité** : WCAG 2.1 compliance
- **SEO** : Best practices
- **Sécurité** : OWASP guidelines
- **Performance** : Optimisations avancées

## Utilisation

1. Ouvrez Notilus Lighthouse via la sidebar ou `Ctrl+Shift+L`
2. Naviguez vers la page à analyser
3. Cliquez sur "Lancer l'audit" ou utilisez `Ctrl+Shift+R`
4. Consultez les résultats et recommandations

## Raccourcis

- `Ctrl+Shift+L` : Ouvrir Notilus Lighthouse
- `Ctrl+Shift+R` : Lancer un audit complet

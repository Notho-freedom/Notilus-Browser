# Terminal Intégré

Notilus inclut un terminal intégré avec deux interfaces disponibles.

## Interfaces disponibles

### Notilus Native
- Interface Flutter native
- Design cohérent avec Notilus
- Performance optimisée
- Personnalisation complète

### XTerm.js
- Terminal avancé avec fonctionnalités complètes
- Support des couleurs et styles
- Compatible avec les terminaux Unix
- Fonctionnalités avancées

## Configuration

Accédez aux paramètres > Terminal pour :
- Choisir l'interface (Native ou XTerm)
- Sélectionner le terminal préféré (PowerShell, CMD, etc.)
- Ajuster la taille de police
- Configurer les options avancées

## Utilisation

1. Ouvrez le terminal via la sidebar
2. Sélectionnez votre terminal préféré
3. Utilisez-le comme un terminal normal
4. Basculez entre les interfaces selon vos besoins

## Raccourcis

- `Ctrl+` (backtick) : Ouvrir/fermer le terminal
- `Ctrl+Shift+` (backtick) : Nouveau terminal

# DevTools Notilus

Les DevTools intégrés de Notilus offrent une suite complète d'outils de développement.

## Onglets disponibles

### Console
- Affichage des logs JavaScript
- Filtrage par niveau (log, warn, error)
- Collapse/expand pour les logs multilignes
- Exécution de code JavaScript

### Network
- Monitoring des requêtes réseau en temps réel
- Filtrage par méthode, statut, type
- Détails complets de chaque requête
- Export des données

### Elements
- Inspecteur DOM avec arbre interactif
- Édition live des styles CSS
- Modification des attributs HTML
- Vue source et vue arborescente
- Export HTML/PDF

### Performance
- Métriques de performance en temps réel
- Graphiques de CPU, RAM, réseau
- Analyse des frames et temps de rendu

### Application
- Gestion du stockage (LocalStorage, SessionStorage, Cookies)
- Visualisation des ressources
- Cache management

## Fonctionnalités avancées

### Mode Inspect
Activez le mode inspect pour sélectionner des éléments directement sur la page.

### Mode Responsive
Simulez différents viewports pour tester la responsivité.

### Export
Exportez les données des DevTools en JSON, CSV ou PDF.

## Raccourcis

- `F12` : Ouvrir/fermer les DevTools
- `Ctrl+Shift+I` : Basculer le mode inspect
- `Ctrl+Shift+R` : Mode responsive

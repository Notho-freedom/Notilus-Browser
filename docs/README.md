## Vue d'ensemble

Notilus Browser est un navigateur moderne basé sur Flutter et WebView2, conçu spécialement pour les développeurs. Il offre des outils avancés de développement, des DevTools intégrés, et une expérience utilisateur personnalisable.

## Fonctionnalités principales

- **DevTools intégrés** : Console, Network, Elements, Performance, Application
- **Notilus Studio** : Outils de test front-end (responsive, mockups, live editing)
- **Notilus Lighthouse** : Analyse complète de performance et audits
- **Terminal intégré** : Interface native ou XTerm.js
- **Mosaïque** : Organisation visuelle de vos contenus
- **Extensions** : Système d'extensions personnalisables
- **Synchronisation cloud** : Firebase Auth avec sync des configurations

## Raccourcis clavier

- `F12` : Ouvrir les DevTools natifs
- `Ctrl+Shift+M` : Basculer la mosaïque
- `Ctrl+Shift+L` : Ouvrir Notilus Lighthouse
- `Ctrl+Shift+S` : Ouvrir Notilus Studio
- `Ctrl+Shift+R` : Lancer un audit Lighthouse

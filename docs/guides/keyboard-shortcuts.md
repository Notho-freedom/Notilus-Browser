# Raccourcis clavier

Liste complète des raccourcis clavier de Notilus.

## Navigation

- `Ctrl+T` : Nouvel onglet
- `Ctrl+W` : Fermer l'onglet actuel
- `Ctrl+Shift+T` : Rouvrir le dernier onglet fermé
- `Ctrl+Tab` : Onglet suivant
- `Ctrl+Shift+Tab` : Onglet précédent
- `Ctrl+R` : Recharger la page
- `Ctrl+Shift+R` : Recharger sans cache
- `Alt+←` : Page précédente
- `Alt+→` : Page suivante

## DevTools

- `F12` : Ouvrir/fermer les DevTools natifs
- `Ctrl+Shift+I` : Basculer le mode inspect
- `Ctrl+Shift+R` : Mode responsive

## Fonctionnalités

- `Ctrl+Shift+M` : Basculer la mosaïque
- `Ctrl+Shift+L` : Ouvrir Notilus Lighthouse
- `Ctrl+Shift+S` : Ouvrir Notilus Studio
- `Ctrl+Shift+R` : Lancer un audit Lighthouse (dans Lighthouse)
- `` Ctrl+` `` : Ouvrir/fermer le terminal

## Paramètres

- `Ctrl+,` : Ouvrir les paramètres
- `Ctrl+K` : Recherche rapide

## Généraux

- `Ctrl+Q` : Quitter l'application
- `F11` : Mode plein écran
- `Esc` : Fermer les panneaux/dialogs

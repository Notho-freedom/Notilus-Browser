# Notilus Browser

Navigateur futuriste style Opera GX, spécialement conçu pour les développeurs.

## Fonctionnalités

- 🎨 Thèmes modernes et avancés (Dark-Red par défaut)
- 📑 Regroupement d'onglets avancé
- 🖥️ Splitscreen multiple
- 🛠️ Outils développeur intégrés
- 🤖 Support IA et automatisation
- 📊 Monitoring et tests intégrés

## Stack Technique

- **Frontend**: Flutter Desktop
- **Moteur de rendu**: CEF (Chromium Embedded Framework)
- **Backend**: Python + Firebase

## Installation

```bash
flutter pub get
flutter run -d windows  # ou macos, linux
```

## Développement

Le projet est structuré de manière modulaire pour faciliter l'ajout de nouvelles fonctionnalités.
